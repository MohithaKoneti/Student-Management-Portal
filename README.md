# Student Management Portal

## Project Description
The Student Management Portal is a project designed to manage student information and academic activities using Agile Scrum methodology.

## Objectives
- Manage student registration and login.
- Maintain student profiles.
- Record attendance and examination marks.
- Manage student fees.
- Generate student reports.

## Methodology
This project follows Agile Scrum. The work is divided into sprints, and each feature is developed and tested incrementally.
