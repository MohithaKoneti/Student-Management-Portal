# Student Management Portal — Product Backlog

## Project Overview
The Student Management Portal is a software system designed to manage student information and academic activities using Agile Scrum.

## Product Backlog

| ID | Feature | Description | Priority |
|---|---|---|---|
| PB1 | Student Registration | Register new students and store their details. | High |
| PB2 | Student Login | Allow users to log in securely. | High |
| PB3 | Student Profile | View and update student information. | High |
| PB4 | Attendance Management | Record and view student attendance. | High |
| PB5 | Marks Management | Store and view examination marks. | High |
| PB6 | Fees Management | Record fee payments and pending fees. | Medium |
| PB7 | Report Generation | Generate student performance and attendance reports. | Medium |

## Scrum Plan

- Sprint 1: Plan requirements and create the basic project structure.
- Sprint 2: Develop student registration and login.
- Sprint 3: Develop student profiles, attendance, and marks management.
- Sprint 4: Develop fees management, reports, and perform testing.

## Definition of Done

A feature is considered complete when it is implemented, tested, and committed to the GitHub repository.
