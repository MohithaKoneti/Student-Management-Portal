# Student Management Portal — Sprint Plan

## Agile Scrum Development Plan

### Sprint 1: Project Planning
- Identify project requirements.
- Create the GitHub repository.
- Prepare the Product Backlog.
- Set up the project structure.

### Sprint 2: Student Registration and Login
- Create the student registration form.
- Develop the login feature.
- Validate user inputs.
- Test registration and login.

### Sprint 3: Student Information and Academics
- Create the student profile feature.
- Develop attendance management.
- Develop marks management.
- Test the features.

### Sprint 4: Fees and Reports
- Develop fees management.
- Generate attendance and academic reports.
- Test all completed features.
- Fix errors and prepare the final project.

## Scrum Review
At the end of each sprint, review the completed work, test the features, and update the Product Backlog when needed.
